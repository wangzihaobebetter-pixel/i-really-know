## 2. 选了 02+01 之后，功能往哪长（这是 Wang 要的那个答案）

主线定在 02+01，产品的下一季功能就不再是开放式的了，它只能往**可解释、可纠正、可归档**长：

1. **锚点确认屏**（02 步骤 1–3）：交完作业先出「我读到这份作业里有 N 个地方站不住」，每条可 `✓ 是这句` / `✗ 换一句` / 拖动改选区。**这是新的第一屏，优先级最高。**
2. **每一问带出处**：问题开头永远带那句被确认过的原文；顶栏常驻「这一问来自你确认过的第 3 处」。追溯链从此完整。
3. **原文即状态机**（01 步骤 5）：判定结果回写到原文的下划线颜色上，一份材料读完就是一张热力图。
4. **批注 / 教师端**是这条线的自然延伸（GoodNotes 的方向）：同一页纸上留批注，老师看到的是学生原话 + 判定 + 出处，而不是一个分数。
5. **导出**（吸收 08 的可取部分）：这条链天然可打印，给导师看的东西不用另做。

**这条线明确放弃的**：03 说出来（语音/答辩陪练）、06 关卡（场次倒计时）、05 间隔（长期记忆调度）。
不是说它们不好——05 的天花板其实最高（Anki 二十年没被取代）——而是它们要的第一屏和 02 冲突，
同一个产品不能有两个第一屏。**05 的到期队列可以在 02 跑通之后作为第二层加回来，02 的确认记录正好是它的输入。**

**这条线解决不了的**（如实写）：多一个确认步骤，第一次使用的路径变长；急着用的学生会觉得啰嗦。
缓解手段只有一个：确认屏必须能一键「都对，直接开始」，否则它会杀掉首次转化。

## 3. 一条必须说出口的负面结论

深度调研（`research/` 三份全文，覆盖 Anki / Duolingo / Quizlet / Elevate 等）**没有找到任何一款大体量产品采用「先自评、再机器判定」**。
Anki 是纯自评（无判定），Quizlet/Elevate 是纯机判（无自评）。

这意味着「自评 vs 判定的落差」既是我们最像样的差异化，**也是一个未被任何人验证过的赌注**。
默认值：**继续押它**，因为它是产品哲学的核心，且 04 与 10 都在为它取数。
但要求：把它当实验对待——第一批真实用户跑完后看落差分布，如果落差不呈现有意义的结构（比如人人都是零落差），就要准备换掉。

## 4. 三档 → 四档（默认值：扩，但代码未动）

Anki 官方手册四档 `Again / Hard / Good / Easy`，SuperMemo 六档 0–5，且不同档位有不同算法后果。
我们是三档，缺的那一档是：**「答错了，但一看标准答案我立刻就认出来了」**。
它和「彻底不会」在学习意义上完全不同，我们现在把两者压在同一档里——这会污染 calibration 指标本身。

**默认值：扩到四档。** 未擅自实现，因为它动的是已存数据的语义（历史三档记录如何映射到四档），
属于产品改动而非 UI 改动。落地时的迁移默认值：历史记录**不重映射**，四档从启用日起生效，
指标按「启用前/启用后」分段统计，不做跨段比较。
